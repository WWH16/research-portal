# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Balanced density: white cards on the `--color-canvas` page, 1px `--color-line` borders, soft elevation only where it helps. Shadows come from one scale in `app.css`, named by job: `shadow-control` (inputs, buttons, in-page cards), `shadow-raised` (a panel standing off the page), `shadow-floating` (menus, option lists, tooltips) and `shadow-overlay` (dialogs, flyouts, toasts). Never write an arbitrary shadow or a shadow colour. Strong type hierarchy in Instrument Sans, tabular figures for counts and dates. ISU green (`--color-isu-green-*`) is the accent; gold only for highlights and the "New" badge. Build with stock Flux components; never hand-style a button.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata (the `--color-pastel*` tokens stay allowed on "needs you" callouts with `class="pastel"`)
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text; 3:1 for large text, borders, and UI controls.
- **Touch / focus:** 44×44px minimum targets on phones (the portal uses `max-sm:h-11` / `max-sm:size-11`); visible focus ring on every interactive element.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal, split by audience
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:**
  - Utilitarian for chrome and admin-only text: labels, buttons, headings, tabs, section names, toasts, admin dialogs and errors ("New", "Upcoming", "Delete announcement?", "Memo not saved. Storage unavailable.").
  - Faculty-facing text keeps full professional sentences: notices, emails, notifications, deadlines, posted dates, empty states, status lines. Full names and full dates ("Friday, December 4, 2026", never "Dec 4"). No clipped headline style.
  - Name the Research Office as the contact point.

## Icon library

- **Library:** Heroicons
- **Package / path:** Bundled with Flux (`livewire/flux`), used as `icon="name"` or `<flux:icon.name />`. Lucide extras live in `resources/views/flux/icon/`.
- **Notes:** Heroicons first. Add a Lucide icon to `resources/views/flux/icon/` only when Heroicons has none, and keep its credit comment. No emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
